# Морковь: сайт на основе Pixso

Сохраняем светлую основу, графитовую типографику, морковный акцент и предметную фотографию исходного макета. Выразительность создают размер фотографии, композиция и живые реакции элементов. Не используем декоративные метрики, вымышленные отзывы, градиентный текст и типовой набор feature cards.

Manrope с кириллицей, один масштаб от 14 до 96px. Основные цвета: #f8f9f5, #222c22, #eb6b38. Поля 5vw, максимальная ширина 1440. Фотографии с радиусом 16px, кнопки 8px.

Главная, каталог, четыре страницы товаров, о магазине, контакты. Список покупок сохраняется локально и формирует запрос наличия и стоимости. Никаких неподтверждённых цен или имитации оплаты.

Движение: Lenis на desktop; GSAP для появления текста и лёгкого параллакса; один сдержанный Vanta fog в первом экране. Фото видно сразу. CSS hover и View Transitions. На мобильных нативный scroll; reduced-motion отключает несущественные эффекты.
