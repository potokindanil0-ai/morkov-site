# «Морковь»: работающий сайт

На основе макета Pixso собран адаптивный многостраничный сайт. HTML доступен без JavaScript; интерактивность подключается отдельным модулем. Сборка не требует зависимостей npm.

## Запуск

Из этой папки:

```sh
npm run build
npm run dev
```

Открыть http://localhost:4173. Через `file://` модули браузера не работают. Для обычного статического хостинга загрузить содержимое `dist/` целиком, включая `site-effects/` и лицензии.

## Структура

```text
build.mjs                  шаблоны всех страниц, генератор HTML
dist/
  index.html               главная
  catalog.html             каталог: поиск и категории
  product-*.html           четыре страницы продуктов
  about.html               о магазине
  contacts.html            контакты и вопросы
  privacy.html             хранение данных и внешние ссылки
  404.html                 страница ошибки
  assets/
    data.js                продукты, тексты, единицы и шаг количества
    app.js                 список покупок, фильтры, диалоги, motion lifecycle
    style.css              дизайн и адаптивность
    hero.webp              фотография первого экрана
    products.webp          четыре предметных изображения
    fonts/                 локальный Manrope и OFL
  site-effects/            Lenis, GSAP/ScrollTrigger, Vanta, Three и лицензии
```

## Что работает

- Поиск по названию с нормализацией регистра и ё/е, категории, совместная фильтрация, URL параметров, пустая выдача и сброс.
- Прямые ссылки на товары, количество с шагом 0,5 кг / 1 шт., описание и раскрывающиеся блоки.
- Общий список покупок: добавление, изменение количества, удаление, сохранение в localStorage, синхронизация вкладок, восстановление после навигации.
- Готовый текст запроса о наличии/ценах, копирование с обратной связью, телефон и Яндекс Карты.
- Мобильное меню, доступные нативные диалоги, Escape, возврат фокуса, клавиатурная навигация.
- Lenis на desktop, GSAP появления и параллакс, один сдержанный Vanta фон, CSS hover/press, переходы между страницами при поддержке View Transitions.
- На телефоне нативная прокрутка и статичный фон; reduced-motion отключает несущественное движение.

## Редактирование

Изменить контент в `build.mjs`, каталог в `dist/assets/data.js`, затем выполнить `npm run build`. Стиль и поведение правятся в `dist/assets/style.css` и `app.js`. Сборка перегенерирует только HTML и favicon, оставляя эти файлы на месте.

## Граница готовой функциональности

Сайт составляет список пожеланий, а не принимает оплаченный заказ. Серверная обработка заказов, реальные цены/остатки, CRM и эквайринг не подключены: данных и доступов для них не предоставлялось. Контактный сценарий полностью работает без имитации отправки. Для e-commerce нужно согласовать эти данные и подключить backend.

Предметные изображения созданы ранее для концепции через встроенный imagegen, оптимизированы в WebP. Это не фото магазина или гарантия текущего ассортимента. Перед использованием как официального сайта желательно заменить их собственными фотографиями продуктов. Чужие помещения, вымышленные отзывы, цены и обещания доставки не использованы.

Manrope получен из официального репозитория Google Fonts; лицензия в assets/fonts. Лицензии библиотек сохранены внутри site-effects/licenses.

## Проверка

`npm run check` проверяет синтаксис генератора и приложения. В браузере проверены основные пять типов страниц на 390, 768, 1024 и 1440px: горизонтального переполнения нет. Пройдены поиск+категория, пустая выдача и сброс, карточка, количество, сохранение после перезагрузки, Escape и меню. Режим reduced-motion предусмотрен на уровне CSS и runtime; отдельная эмуляция системной настройки в этом браузере недоступна.
